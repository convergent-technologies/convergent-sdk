# Security

Report a vulnerability through GitHub's private reporting form:
[Report a vulnerability](https://github.com/convergent-technologies/convergent-sdk/security/advisories/new),
also reachable from the Security tab of this repository. Say what you found,
where, and how to reproduce it.

If you prefer email, write to
[support@convergent.dev](mailto:support@convergent.dev) with "security" in the
subject line.

We will acknowledge within two business days.

Do not open a public issue for a vulnerability.
