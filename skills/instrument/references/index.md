# Get started

The Get started page takes an agent from nothing to one run visible in a
Convergent workspace. It gives the install command, where to mint an
ingestion key, the two environment variables to export for the key and the
release, and a traced run whose model call is an OpenAI client call. Most of the
page reads a `check()` report line by line against a full
example, so you can tell a setup that reached the server from one that only
looks configured. It closes with the workspace page to open once a run has
arrived.

Page: `python/docs/index.md` in https://github.com/convergent-technologies/convergent-sdk.
