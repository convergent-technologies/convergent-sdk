# Enforce the verification loop with a plugin

The Enforce the verification loop with a plugin page describes the Claude Code
plugin that turns step 4 from a request into a gate. It gives the two install
commands, says what the checker and the independent verifier each have to pass
before a session can finish, explains the `fix` and `ask` classifications, and
lists the waive and cancel commands and every bound that releases the loop
unverified. Send a user here when they ask how to make verification enforced,
what is blocking their session, or how to turn the gate off.

Page: `python/docs/plugin.md` in https://github.com/convergent-technologies/convergent-sdk.
